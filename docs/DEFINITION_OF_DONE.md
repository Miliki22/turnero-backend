# Definition of Done (DoD)

Una tarea/feature está "Done" cuando:

- [ ] Funcionalidad implementada y funcionando
- [ ] Tests agregados/actualizados (pytest) y pasan
- [ ] Validaciones server-side completas
- [ ] Sin prints/debug
- [ ] Código con PEP8 + type hints + docstrings
- [ ] Refactor aplicado si el cambio infló demasiado un archivo
- [ ] README y/o docs actualizados (si aplica)
- [ ] Cambio revisado y aprobado por Miliki antes de merge
